# AFTERLIGHT / RIPPLE

波紋の光で、文章を送る。

画面に表示した青い波紋を別の端末のカメラで読み取り、合い言葉で文章を復号するWebアプリです。インストール可能なPWAとして動作します。

![実際に生成した送信用の波紋](docs/images/ripple-output.png)

*上の画像は実際の送信模様です。アプリ画面のスクリーンショットではありません。*

## 使い方

1. 送信端末で「送る」を選び、文章と8文字以上の合い言葉を入力します。
2. 「波紋を生成して送信」を押します。
3. 受信端末でも同じアプリを開き、「受け取る」からカメラを起動します。
4. 送信画面の4色の目印をすべてカメラに入れます。
5. 同じ合い言葉で復号します。取り逃した情報は次の周回で補えます。

上限は5,000文字です。標準は1枚0.2秒、高速は0.1秒。読み落とす場合は「安定優先」か「ゆっくり」に切り替えてください。「動画を保存」は2周分の映像をWebMまたはMP4として記録します。

## PWA

Android・PCではブラウザのインストール機能、iPhone・iPadではSafariの共有メニューから「ホーム画面に追加」を使います。

初回はオンラインで開き、オフライン利用の準備ができた表示を確認してください。その後はアプリ画面・暗号化・送受信・動画生成を端末内で実行できます。カメラの許可が必要です。更新版は操作中に自動再起動せず、「更新して再起動」で適用します。

## ローカル実行と設置

ビルドや依存パッケージのインストールは不要です。リポジトリのルートで実行します。

```sh
python3 -m http.server 8080
```

同じPCで `http://localhost:8080/` を開きます。別のスマホから利用する場合は、このフォルダーをHTTPSの静的ホスティングに配置してください。LAN内の通常のHTTPアドレスでは、カメラやPWAが使えない場合があります。

## 仕組み

- 円形のsin/cos波を直接描画し、24×24の低周波成分へ符号化データを重ねます。GSシミュレーションは使いません。
- 1枚に28 bytesの本文を格納。K9畳み込み符号、フレームCRC16、全文CRC16で読み取りを検証します。
- 文章は有効な場合にgzip圧縮し、AES-256-GCMで暗号化します。合い言葉からの鍵導出はPBKDF2-HMAC-SHA256、600,000回です。
- 受信は4色マーカーの位置合わせ、波紋成分の除去、soft Viterbi、認証付き復号の順に処理します。
- 合い言葉・平文をサーバーへ送信しません。生成した暗号化模様はIndexedDBへ一時保存し、再生成時などに削除します。

## 確認した範囲

開発環境では、繰り返しの少ない漢字5,000文字を358枚の模様に変換し、合成した斜め撮影画像から全文復号しました。生成計算は合計約8.5秒でした。一時保存や端末性能によって実際の所要時間は変わります。

0.2秒・0.1秒切り替えの動画をH.264／360×360へ縮小圧縮した場合も、358枚すべてから全文復号できました。実機カメラでの高速受信、各ブラウザのインストール動作、YouTube再圧縮後の動作は未確認です。

## テスト

Node.js 24以降で、追加パッケージなしに実行できます。

```sh
npm test
npm run test:optical
```

光通信テストは5,000文字の模様を生成し、斜め撮影の合成画像から復号します。生成物は`.tmp-ripple/`へ保存します。動画圧縮テストには別途Python、Pillow、NumPy、FFmpegが必要です。
